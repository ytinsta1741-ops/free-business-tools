# Code of Conduct

## Our pledge

We — the maintainers and contributors to the [BusinessOS](https://businessos.biz) free business tools — pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Our standards

Behaviour that helps this community:

- **Be helpful** — a math bug fix or a i18n improvement makes life easier for real freelancers and small businesses
- **Be clear** — link the tax authority page, the accounting textbook, the spec, when you can
- **Be patient** — this is a side-project maintained around building [BusinessOS](https://businessos.biz); responses may take a few days
- **Be respectful** — of contributors' time, of users' privacy (these tools have zero tracking; PRs must not add any)
- **Be constructive** — "this calculation is wrong for the UK" is helpful; "this repo is trash" is not

Behaviour that is not welcome:

- Harassment, threats, or personal attacks
- Discriminatory language on any basis
- Publishing others' private information
- Adding tracking, analytics, ads, cookies, or third-party fetches to any tool
- Adding paid dependencies or "freemium" upsells
- Submitting spam PRs, keyword-stuffed doc changes, or SEO-only edits
- Using the issue tracker for support with the main [BusinessOS](https://businessos.biz) app (use the site's contact channel for that)

## Enforcement

Report unacceptable behaviour by:

- Opening a private security advisory: https://github.com/ytinsta1741-ops/free-business-tools/security/advisories/new
- Reaching out via [businessos.biz](https://businessos.biz)

Maintainers may remove comments, close PRs/issues, or ban contributors for behaviour that violates these standards.

## Scope

This applies to all project spaces:
- This GitHub repository
- Any [BusinessOS](https://businessos.biz)-branded issue trackers, discussion boards, or chat channels
- Public representation of the project (e.g. on X, LinkedIn, Product Hunt)
